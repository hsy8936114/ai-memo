# 시나리오 02: 메모 수정

- **우선순위:** P1 (높음)
- **대상 URL:** http://localhost:3000
- **근거:** CRUD의 핵심 기능이며, 수정 시 AI 요약이 재생성되고 `updated_at`이 갱신되는 등 부수 동작이 많아 회귀 위험이 크다.

## 사전 조건

- 시나리오 01로 만든 메모(`[E2E] 작성-<타임스탬프>`, 업무, 태그 `e2e`)가 존재한다.
  - 독립 실행이 필요하면 테스트 시작 시 같은 절차로 메모를 먼저 생성한다.
- 기존 시드 메모(예: `프로젝트 회의 준비`)는 수정하지 않는다.

## 테스트 데이터

| 항목        | 변경 전                       | 변경 후                         |
| ----------- | ----------------------------- | ------------------------------- |
| 제목        | `[E2E] 작성-<타임스탬프>`     | `[E2E] 수정-<타임스탬프>`       |
| 카테고리    | 업무                          | 학습                            |
| 내용        | `E2E 테스트로 작성한 메모입니다.` | `수정된 내용입니다.`        |

## 절차 및 기대 결과

| #   | 동작                                                         | 기대 결과                                                                 |
| --- | ------------------------------------------------------------ | ------------------------------------------------------------------------- |
| 1   | 메인 페이지 접속 후 대상 메모 카드를 찾는다                  | 카드가 목록에 보인다                                                      |
| 2   | 해당 카드의 `편집` 버튼 클릭                                 | `메모 편집` 제목의 모달이 열린다. 카드 클릭으로 상세 보기가 열리지 않는다 |
| 3   | 폼 초기값 확인                                               | 제목·카테고리·내용·태그가 기존 값으로 채워져 있다                         |
| 4   | 제목을 `[E2E] 수정-<타임스탬프>`로 변경                      | 입력값이 반영된다                                                         |
| 5   | 카테고리를 `학습`으로 변경                                   | 선택값이 반영된다                                                         |
| 6   | 내용을 `수정된 내용입니다.`로 변경                           | 편집기와 미리보기에 반영된다                                              |
| 7   | `수정하기` 클릭 (편집 모드의 저장 버튼 이름)                 | 모달이 닫힌다                                                             |
| 8   | 목록 확인                                                    | 같은 카드가 새 제목과 `학습` 배지로 갱신되고, **카드 개수는 그대로**다    |
| 9   | 이전 제목 검색                                               | 이전 제목의 카드는 더 이상 없다 (새 카드가 추가된 것이 아님을 확인)       |
| 10  | 카드를 클릭해 상세 보기 열기                                 | 새 제목, `학습` 배지, 수정된 내용이 표시된다                              |
| 11  | 페이지 새로고침                                              | 수정 내용이 유지된다 (영속화 검증)                                        |

## 정리(Cleanup)

- 03번 시나리오로 대상 메모를 삭제한다.

## 참고 / 주의

- 목록은 `created_at` 내림차순이므로 수정해도 카드 **위치는 바뀌지 않는다.**
- 수정 시에도 AI 요약이 재생성되므로 저장에 수 초가 걸릴 수 있다. 요약 문구 자체는 비결정적이라 **내용 일치로 검증하지 않는다.**
- 편집 중 `취소`를 누르면 변경이 저장되지 않아야 한다. (P2 부정 케이스로 별도 작성 권장)
