# 시나리오 01: 메모 작성

- **우선순위:** P0 (최고)
- **대상 URL:** http://localhost:3000
- **근거:** 앱의 핵심 가치이며, 수정·삭제 시나리오가 모두 "메모가 존재한다"는 전제에 의존한다.

## 사전 조건

- 개발 서버가 `http://localhost:3000`에서 실행 중이고 Supabase 환경변수가 설정되어 있다.
- 테스트 데이터는 충돌을 피하기 위해 제목에 고유 접두사(`[E2E] 작성-<타임스탬프>`)를 붙인다.
- `ANTHROPIC_API_KEY`가 없으면 AI 요약은 생성되지 않는다. (요약은 이 시나리오의 필수 검증 대상이 아니다.)

## 테스트 데이터

| 항목     | 값                                          |
| -------- | ------------------------------------------- |
| 제목     | `[E2E] 작성-<타임스탬프>`                   |
| 카테고리 | 업무                                        |
| 내용     | `E2E 테스트로 작성한 메모입니다.`           |
| 태그     | `e2e`                                       |

## 절차 및 기대 결과

| #   | 동작                                                             | 기대 결과                                                              |
| --- | ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 1   | 메인 페이지 접속                                                 | 헤더 `📝 슈퍼 메모앱`, 탭 제목 `슈퍼 메모앱`, 로딩 후 메모 목록 표시   |
| 2   | 현재 `총 N개의 메모` 텍스트에서 N을 기록                         | N 확보                                                                 |
| 3   | `새 메모` 버튼 클릭                                              | `새 메모 작성` 제목의 모달이 열린다                                    |
| 4   | 제목 입력란(`제목 *`)에 제목 입력                                | 입력값이 반영된다                                                      |
| 5   | 카테고리를 `업무`로 선택                                         | 선택값이 반영된다                                                      |
| 6   | 내용 편집기(`내용 * (마크다운 지원)`)에 내용 입력                 | 좌측 입력과 우측 미리보기에 내용이 표시된다                            |
| 7   | 태그 입력란에 `e2e` 입력 후 Enter                                | `#e2e` 태그가 추가되고 입력란이 비워진다                               |
| 8   | `저장하기` 클릭                                                  | 모달이 닫힌다 (저장 중에는 AI 요약 때문에 수 초 걸릴 수 있음)          |
| 9   | 목록 확인                                                        | 새 메모 카드가 **목록 맨 앞(최신순)** 에 표시된다                      |
| 10  | 카드 내용 확인                                                   | 제목, `업무` 배지, `#e2e` 태그가 보인다                                |
| 11  | `총 N+1개의 메모` 확인                                           | 개수가 1 증가한다                                                      |
| 12  | 페이지 새로고침                                                  | 새로고침 후에도 메모가 남아 있다 (Supabase 영속화 검증)                |

## 정리(Cleanup)

- 03번 시나리오의 삭제 절차 또는 `[E2E]` 접두사 메모를 직접 삭제해 테스트 데이터를 남기지 않는다.

## 참고 / 주의

- 제목 또는 내용이 비어 있으면 `제목과 내용을 모두 입력해주세요.` 경고창이 뜨고 저장되지 않는다. (P1 부정 케이스로 별도 작성 권장)
- 내용 편집기는 `ssr: false` 동적 로딩이라 `편집기를 불러오는 중...`이 먼저 보일 수 있다. 편집기 영역(`data-testid="memo-content-editor"`)이 나타날 때까지 대기해야 한다.
- 새 메모 카드는 `data-testid="memo-card"`로 찾을 수 있다.
